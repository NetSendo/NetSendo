# Security Policy

## Supported Versions

Security fixes are released for the latest minor version only. Update to the newest release before reporting.

| Version | Supported          |
| ------- | ------------------ |
| 2.7.x   | :white_check_mark: |
| < 2.7   | :x:                |

The newest release is always on the [Releases](https://github.com/NetSendo/NetSendo/releases) page.

## Reporting a Vulnerability

We take the security of our software seriously. If you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

### How to Report

If you believe you have found a security vulnerability in NetSendo, please report it privately in one of these ways:

- **GitHub (preferred):** open the [Security tab](https://github.com/NetSendo/NetSendo/security) and choose **Report a vulnerability**. The report stays private between you and the maintainers.
- **Email:** security@netsendo.com

You should include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Any relevant logs or screenshots.

### What to Expect

- We will acknowledge receipt of your report within 2 business days.
- We will provide an estimated timeframe for addressing the vulnerability.
- We will notify you when a fix has been released.
